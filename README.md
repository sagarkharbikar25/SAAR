# SAAR — Smart AI Automation & Assistant Robot

SAAR is an advanced AI-powered desktop assistant completely built using **Python**.  
It is designed to automate an entire computer system using both **voice commands** and **text prompts**.

SAAR combines:
- Local AI models through Ollama
- Cloud AI integration using Gemini API
- Human-like voice interaction
- Intelligent system automation
- Coding assistance
- Productivity workflows
- AI-powered project generation

It functions as a hybrid AI operating assistant capable of running in both **offline** and **online** environments.
